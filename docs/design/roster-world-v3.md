# 로스터 v3: 세계 설화 확장 (roster-world-v3)

상태: 초안, 디렉터 승인 대기. `roster-korea.json/.md`, `roster-swap-v2.md` 미수정.
데이터: `roster-world-v3.json` (90장 전체, region 필드 신규).
불변: 슬롯 구조와 cards.js 수치(tier/cost/points/bonus/evolvesTo/evolveReq), 슬롯별 color. 캐릭터만 교체. 룰 변경 없음.
v2(`roster-swap-v2.md`)는 v3 승인 시 폐기 권고. v2 채택안 재평가는 (d) 참조.

가정: (1) 인지도 기준은 "한국 20~40대가 이름만 듣고 안다". 설문 데이터 없이 기획 판단이므로 QA/디렉터 검수 필요. (2) region 은 표시 전용이며 게임 효과 없음. (3) 라인 구조(3단/2단/단일)는 슬롯이 정하므로, 원래 3단이던 한국 라인을 2단으로 줄이는 것을 허용.

### 색 매핑 분석 (지역 = 색 진영)
결론: 전면 채택 불가. 부분 채택도 의미 없음. 지역은 카드 테두리 문양으로만 표시.

근거:
- 3단 라인 12개는 stage1~3 색이 같아서 라인 단위 매핑이 가능하다.
- 2단 라인 18개 중 16개는 t1 색과 t2 색이 다르다(같은 색은 t1-019/t2-017 quick, t1-023/t2-021 heal 둘뿐). 한 라인(한 지역)이 두 색에 걸치므로 "색 = 지역"이 성립하지 않는다.
- 단일/희귀/전설도 색 분포가 슬롯 고정이라 지역 몰아주기 시 한국 비중 48%와 충돌한다. 5색에 8개 지역을 나눌 수 없다.
- 색별 슬롯 수가 달라(3단 기준 적3 / 흑3 / 황2 / 청2 / 백2) 한 지역에 한 색을 주면 지역 크기가 강제로 정해진다.

대안(채택): 지역 코드 8종을 테두리 문양으로 표시(JSON `meta.regions[].motif`). 색 친화는 3단에서만 자연 발생시킨다.

### 선정 원칙
1. 진화/성장 서사가 이야기로 이어지는 라인을 3단 우선 배정.
2. 3단 후보 중 서사가 2단으로 충분하면 2단으로 압축(주몽, 도깨비, 구렁이→용).
3. 인지도 애매하면 제외. 인지도가 높아도 현대 각색 IP 비중이 큰 소재(드래곤볼식 손오공, 디즈니 인어공주 등)는 원작 텍스트만 쓰는 조건으로 채택.

## (f) 게임 정체성 영향

### 권고 요약
1. 자원은 한국 보물 5종(노리개/나전함/복주머니/청자/백자) + 와일드 마패 유지. 세계 보물로 확장하지 않는다.
2. 가제 '조선 스플렌더'는 변경 권고.

### 근거
- 자원(보석 토큰)은 추상 오브젝트이고 색 5종이 룰 구조와 결합. 세계 보물로 확장하면 아트·UI·툴팁 비용만 늘고 룰 이득이 없다.
- 한국 보물 자원은 "조선 장터"에 세계의 이야기가 모인다는 프레임과 어울린다(보부상이 세계 설화를 거래). 한국 정체성은 자원·UI·사운드가 담당하고, 카드는 한국 + 세계로 구성.
- '조선'은 시대 한정, 세계 설화 47장과 맞지 않는다.
- '스플렌더'는 기존 보드게임 `Splendor`(Space Cowboys) 상표로 보인다. 정식 출시 명칭에는 사용 불가 가능성이 높다. 법무 검토 필요(기획 판단 범위 밖). 개발 코드명 Next-splender는 내부용으로 유지 가능.

### 제목 후보 3개
| 순위 | 제목 | 의미 |
|---|---|---|
| 1 | 옛날 옛적 장터 | "옛날 옛적에"로 시작하는 한국 구연 문법 + 장터 거래 은유. 세계 이야기를 포괄 |
| 2 | 이야기 보물상 | 보부상 + 이야기 수집 + 보물 자원. 한국 보물 5종과 연결 |
| 3 | 설화 장터 | 가장 간결. 한국 설화 중심 + 세계 설화 포용 |

### 세계관 프레임 제안
조선 장터에 모여든 보부상들이 각 나라의 이야기를 풀어놓고 이야기꾼은 그 이야기를 모아 간다. 카드 = 이야기꾼이 모으는 이야기. 성장 버튼 = 이야기를 이어 가기. 한국 보물이 거래 단위. 이 설명은 설정용 한 줄로 충분하며 룰 영향 없음.

### UI/아트 영향
- 지역 문양 테두리 8종(KR/EA/EU/HERO/GR/NO/EG/ME). 카드 프레임 레이어로 분리하면 스프라이트 재작업 없음.
- 도트 해상도에서 서양/중동 의복 구분을 위해 headwear/outfit 신규 값 필요(아래 요청 참조).
- 한국 한자 오행 색 표기(赤黑黃靑白) 유지. 지역 문양이 색과 무관하다는 점을 튜토리얼 툴팁에 한 줄 표기.
