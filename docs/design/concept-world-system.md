## 0. 참조작 진화 시스템 분석 (pokemon-splendor)

읽은 범위: `src/core/engine.js` 의 `evolveOptions`(105-118), `doEvolve`(414-430), `toEvolvePhase`(442-445), `getPoints`(40), `getRanking`(120-). `src/data/cards.js` 일부(T1~T2 앞부분).

### 동작 요약
- 메인 액션(구슬 획득/구매/예약) 후 `toEvolvePhase`가 호출된다. 진화 가능 옵션이 1개 이상이면 `EVOLVE` 페이즈로 들어가고, 없으면 턴 종료.
- 옵션 조건: 내 tableau 카드의 `evolveReq`(색별 보너스 임계치)를 현재 보너스가 충족하고, 다음 단계 카드(`evolvesTo`)가 내 예약패(hand) 또는 테이블 공개 슬롯에 있을 때.
- 실행: 다음 카드를 가져와 tableau의 이전 카드 자리에 교체. 이전 카드는 `player.evolved`로 이동(보너스는 유지된다는 것이 디렉터 설명). 진화하면 턴 종료.
- 점수는 tableau 카드 `points` 합이므로, 이전 카드 점수는 빠지고 새 카드 점수로 교체된다. 랭킹 타이브레이크에 진화 횟수 사용.

### 장점
1. 조건 충족 시 무료로 카드가 "업그레이드"되는 보상감. 엔진 곡선(보너스 쌓기)과 자연스럽게 연결.
2. 진화 횟수가 타이브레이크 -> 진화 자체가 목표가 됨.
3. 예약패를 진화용으로 쓰는 전략 깊이.

### 문제점 (모바일/캐주얼/멀티 관점)
| # | 문제 | 근거 | 영향 |
|---|---|---|---|
| P1 | 다음 단계 카드가 테이블에 나와 있어야 하거나 내 예약패에 있어야 함 | `evolveOptions`의 `hand`/`findOnTable` 분기 | 조건을 채워도 카드 노출 운에 달림. 상대가 그 카드를 사 가면 라인이 죽음(의도치 않은 견제) |
| P2 | 진화가 별도 페이즈 + 진화하면 턴 종료 | `toEvolvePhase`, `doEvolve` -> `endTurn` | 매 턴 추가 탭/확인 단계. 진화하는 턴에는 메인 액션과 별개로 한 턴을 소모하는 구조가 아니라 메인 액션 뒤 추가 입력이 강제됨(비동기에서 대기 왕복 증가) |
| P3 | `evolvesTo: null`인 막다른 카드 다수(예: t1-014, 015, 032, 034, 035) | cards.js | 진화 라인 체감 편차, 정보 부담 |
| P4 | 조건 색이 카드마다 임의(예: t1-006 구구는 자기 색과 무관) | `evolveReq` 데이터 | 규칙이 외워야 할 표가 됨. 튜토리얼/직관성 낮음 |
| P5 | 진화 시 이전 카드 점수가 사라지는 구조 | `getPoints`는 tableau만 합산 | 점수 하락 가능성이 있으면 혼란. (데이터상 단조 증가인지는 미확인) |
| P6 | 진화 조건이 막혔을 때 우회 수단 없음 | 코드상 대체 경로 없음 | 막히면 그냥 손해 |

## 1. 세계관 후보 비교

평가 척도: 5점 만점(5=가장 좋음). 친숙도는 타깃(한국 직장인 중심, 글로벌 확장 고려).

| 항목 | A. 세계 신화 크리처 | B. 동양 사신/오방색·오행 | C. 공룡/고생물 | D. 서양 판타지 생물 | E. 아기동물 성장/변태 |
|---|---|---|---|---|---|
| 친숙도 국내 | 5 (구미호·이무기·도깨비·용) | 5 (청룡 백호 주작 현무) | 4 | 3 | 4 |
| 친숙도 해외 | 4 (용·히드라·불사조·유니콘) | 2~3 (동아시아 외 낮음) | 5 | 5 | 4 |
| 저작권 안전성 | 4 (원전 PD. 현대 디자인 회피 필요) | 5 (고전·민화 PD, 현대 파생 적음) | 4 (고생물 사실 PD. 영화 디자인 회피) | 3 (D&D/톨킨/해리포터 등 IP 지뢰밭) | 5 |
| 진화 서사 적합성 | 5 (꼬리 수, 머리 수, 이무기->용, 알->불사조) | 3 (사신 자체는 "고정 신격", 성장 서사 약함) | 3 (진화는 종 단위 시간. 개체 성장과 불일치, "진화 시스템" 직관은 있음) | 4 (드래곤 해츨링->성룡) | 4 (애벌레->나비는 직관적이나 단계 수·변화폭이 작음) |
| 5색+조커 매핑 | 3 (자연 매핑 없음, 임의 지정 필요) | 5 (오행 = 정확히 5색. 조커 = 여의주 등) | 2 (색 매핑 억지. 육식/초식 등 분류는 색과 무관) | 3 (4원소+α) | 2 (서식지 분류 등 억지) |
| 수집욕/캐릭터 매력 | 5 (이야기와 개성이 큼) | 3 (4~5종으로 종류가 적음. 확장 한계) | 4 (아이템 인기, 성인 수집층) | 4 | 4 (귀여움 강함, 직장인 캐주얼에 어필. 단 수집 깊이 낮음) |
| 리스크 | 현대 창작물과 닮음(나루토 구미호, 드래곤볼 신룡 등), 색 매핑 직관 부족 | 해외 소구 약함, 콘텐츠 풀 협소 | 종 수는 많으나 개체 변신 서사 부재, 어린이 이미지 | IP 오염 위험 최고, 레드오션 | 서사/난이도 얕음, 성인 수집욕 약함, 확장 한계 |

### 독립 평가 메모
- A 단독은 색 매핑이 약하고, B 단독은 성장 서사와 콘텐츠 풀이 약하다. 둘의 약점이 서로 상보적이다.
- "퍼블릭 도메인 + 진화 서사"만 보면 A가 최상. "스플렌더 5색 + 직관적 규칙"까지 보면 B의 오행이 최상.
- 디렉터 후보 외 제시: **F. 요괴/정령 도감(한중일 통합)**. 콘텐츠 풀은 가장 넓으나, 일본 요괴는 현대 작가 디자인(미즈키 시게루 등)이 아직 저작권 보호 중이고 요괴워치 등 현대 IP 밀도가 높아 A에 흡수하고 단독 후보로는 기각.

### 추천: **A + B 결합 = "오행 신화 크리처"**
- 크리처는 A(세계 신화·민담, 동아시아 비중 70% 이상, 서양 신화는 소수 확장), **색 체계와 규칙 골격은 B의 오행**을 사용.
- 근거
  1. 오행 5색 = 스플렌더 5색에 1:1 대응. 억지 매핑 없음.
  2. 오행 상생(木->火->土->金->水->木)을 "변화 조건"의 규칙으로 쓰면 참조작 문제 P4(임의 조건)를 해결하면서 설명 가능한 규칙이 된다 (4절).
  3. 성장/변신 서사가 민담에 이미 존재: 잉어->이무기->용(등용문), 여우->구미호, 새끼 호랑이->산군->백호, 알->봉황.
  4. 국내 친숙도 최상, 해외는 "용/불사조/히드라/유니콘"으로 연결 가능.
  5. 크리처 풀이 크므로 확장팩(카드 추가) 여지 큼.
- 추천 보류 조건: 해외 출시 비중이 크면 서양 신화 비율을 높이는 선택지를 열어 둔다(열린 질문).

### IP 주의사항 (아트/프로그래밍/마케팅 공통)
1. **"원전이 PD"여도 "현대 작품의 묘사"는 별개 저작물이다.** 이름·외형·설정·고유 연출을 따르지 않는다.
2. 피해야 할 구체 예시(비망라)
   - 구미호: 나루토 쿠라마식 주황 거대 여우 + 붉은 눈, 포켓몬 식스테일/나인테일의 외형·색 조합, tvN 드라마 구미호 연출.
   - 용: 드래곤볼 신룡(Shenron) 형태/이름, 센과 치히로 하쿠, 쿵푸팬더·뮬란 무슈 등 상업 영화 용 디자인.
   - 도깨비: 드라마 "도깨비"의 비주얼, 호돌이·수호랑 등 올림픽 마스코트.
   - 서양 판타지: D&D 소유 몬스터(Beholder, Mind Flayer, Displacer Beast, Owlbear 등)와 해리포터·톨킨 고유 명칭/설정.
   - 일본 요괴: 게게게의 키타로, 요괴워치 등 현대 디자인.
   - 중국: 서유기 캐릭터는 PD이나 드래곤볼/현대 영상물의 외형은 회피.
3. 안전한 참고원: 조선 민화(까치호랑이 등), 고분벽화(사신도), 산해경·고전 문헌 서술, 고대 그리스·북유럽 원전 서술. 단, 박물관·기관 사진/복제본은 이용 조건(공공누리 등) 확인 필요.
4. 번역본·현대 재해석 삽화는 별도 저작권. 원전 서술을 기준으로 아트가 독자 해석.
5. **아트 제작 방식 주의:** 생성형 AI 단독 산출물은 저작권 등록 곤란, 유사 디자인 혼입 위험. 정책 결정 필요(열린 질문).
6. 작명: 고유명사(구미호, 이무기 등)는 일반명이라 사용 가능하나 별칭/설정 문구(예: 특정 작품의 대사·기술명) 금지. 게임명은 상표 검색 후 확정.
7. **"스플렌더" 규칙 차용:** 게임 메커닉 자체는 일반적으로 보호 범위가 좁으나, 명칭·일러스트·카드 텍스트·컴포넌트 배치의 직접 복제는 금지. 법무/라이선스 검토를 열린 질문에 올림.

## 2. 핵심 시스템 (추천 세계관 기준)

### 2.1 스플렌더 룰 매핑
| 스플렌더 | 본 작품 | 비고 |
|---|---|---|
| 보석 5색 토큰 | **기운(氣) 5색** : 木 청록 / 火 적 / 土 황 / 金 백 / 水 흑 | 색각 이상 대응으로 한자·문양 아이콘 병기 필수(아트 요청) |
| 조커(금) | **여의주** | 만능 기운. 예약(알 품기) 시 획득. 변화 조건 부족분 1칸 대체에도 사용 (신규 용도) |
| 개발 카드(영구 할인 + 점수) | **크리처** (1단계 유년체를 구매하면 내 도감에 등록) | 보너스 색 = 크리처의 오행. 구매 비용은 기운 |
| 3티어 시장 | **라인 규모 티어**: T1=2단계 라인(소), T2=3단계 라인(중), T3=3단계 라인(대, 신수급) | 시장에는 항상 1단계 카드만 진열 |
| 예약 | **알 품기**: 시장 카드 또는 덱 맨 위를 비공개로 예약 | 최대 3장. 덱에서 예약한 카드는 상대에게 비공개 |
| 귀족 | **영물/수호신**(산신령, 용왕, 삼신할미, 옥황 등) | 인원+1 장. 보너스 요구 충족 시 턴 종료에 자동 방문, 3점 |
| 기운 보유 상한 | 10 (참조작 `MAX_TOKENS` 동일 취급, 값 확정은 시뮬레이션) | 초과 시 버림 |
| 종료 | 15점 도달 시 해당 라운드 종료 후 결산 | 5절 |

### 2.2 전용 성장 시스템: **변화(變化)**
참조작의 "테이블/예약패의 다음 카드로 교체" 방식을 버리고 **"내 크리처 위에 성장 카드를 얹는" 방식**으로 재설계.

#### 규칙
1. **라인(계통)**: 한 크리처 라인은 2~3개 단계 카드 세트. 시장에는 1단계 카드만 나오고, 구매 시 해당 라인의 2·3단계 카드는 "내 도감 슬롯"에 앞면 공개로 옆에 붙는다(내 전용, 상대가 가져갈 수 없음).
2. **변화 조건**: 각 단계 카드에 인쇄된 `변화 조건` = 특정 색 보너스 N개 이상 (보너스 = 보유 크리처가 주는 영구 할인 수).
3. **조건 색 규칙(오행 상생)**: 조건 색은 항상 "내 오행을 낳는 색"이다. 木->火->土->金->水->木 순서에서 직전 색. 예) 火 크리처는 木 보너스를 요구, 水 크리처는 金 보너스를 요구. 라인마다 임의 조건을 외울 필요 없음.
4. **조건 부족 시 여의주 대체**: 조건 부족 1칸까지 여의주 1개를 소모해 충족 처리(턴당 1회). 막힘 문제(P6) 해소 및 조커의 사용처 확대.
5. **변화 실행 = 무료 행동, 턴당 1회, 턴 종료 아님.** 메인 액션 전 또는 후 중 아무 때나 가능. 별도 강제 페이즈 없음. 가능할 때 해당 크리처에 발광 표시 + "변화" 버튼 노출. 자동 변화 설정(자동/묻기) 제공.
6. **보너스·점수**: 변화 후 보너스는 이전 단계 보너스를 포함하며 +1(다른 색 또는 동색). 점수는 각 단계 카드에 "그 단계의 총점"이 인쇄되며 단조 증가(하락 금지, 데이터 검수 규칙). 이전 단계 카드는 아래로 겹쳐 보존.
7. **공개 상태**: 도감 슬롯은 공개 정보라서 상대가 내 변화 타이밍을 읽을 수 있음(전략성 유지).
8. 막다른 카드 없음: 모든 크리처는 최소 2단계. (단독종이 필요하면 별도 "전설" 카드 유형으로 분리, 열린 질문)
9. 타이브레이크: 동점 시 (1) 변화 횟수 많은 쪽, (2) 크리처 수 적은 쪽, (3) 공동 우승. (참조작 순서 계승)

#### 참조작 문제 대응표
| 문제 | 해결 |
|---|---|
| P1 노출 운/견제 | 다음 단계는 내 도감에 이미 있음. 노출 운 0, 의도치 않은 라인 파괴 0 |
| P2 강제 페이즈/턴 소모 | 자유 행동, 별도 페이즈 없음, 자동 설정 |
| P3 막다른 카드 | 시장 카드는 전부 성장형 (단독 전설 제외) |
| P4 임의 조건 | 오행 상생 규칙으로 일원화 |
| P5 점수 하락 | 단계 점수 단조 증가 |
| P6 막힘 | 여의주 1칸 대체 |

#### 예외/엣지 케이스 (QA용)
- 같은 턴에 조건을 충족시키는 구매 후 즉시 변화 가능 (구매 -> 변화 순서 허용).
- 변화로 보너스가 늘어 귀족 조건이 충족되면 턴 종료 시 방문 처리.
- 변화 1회 제한: 같은 턴에 2단계 연속 변화 불가(1단계->3단계 점프 금지).
- 여의주 대체는 조건 1칸 부족일 때만, 턴당 1회.
- 비동기 타임아웃 시 자동 변화는 "자동" 설정자만 수행, 그 외 변화 보류.

### 2.3 샘플 진화 라인 3개 (가안, 수치는 시뮬 전 임시)
오행: 木 청록 / 火 적 / 土 황 / 金 백 / 水 흑. 비용은 색 약자.

#### 라인 1. 구미호 (火, T2 라인) : 꼬리 수 = 성장 단계
| 단계 | 이름 | 보너스 | 총점 | 변화 조건 | 서사 |
|---|---|---|---|---|---|
| 1 | 새끼 여우 | 火 | 1 | 木 보너스 2 | 꼬리 1개 |
| 2 | 오미호(五尾狐) | 火 + 金 | 3 | 木 보너스 4 | 꼬리 5개, 영리해진 여우 |
| 3 | 구미호(九尾狐) | 火 + 火 | 6 | - | 꼬리 9개, 천 년 묵은 영물 |
- 시장 구매 비용(1단계): 火1 木2 土1 (가안).
- 주의: 외형은 "꼬리 수 + 한복·민화풍 장식" 등 전통 모티프로, 나루토 쿠라마·포켓몬 나인테일의 색·형태 조합 회피.

#### 라인 2. 잉어 -> 이무기 -> 용 (水, T3 라인)
| 단계 | 이름 | 보너스 | 총점 | 변화 조건 | 서사 |
|---|---|---|---|---|---|
| 1 | 잉어 | 水 | 1 | 金 보너스 2 | 등용문을 오르는 잉어 |
| 2 | 이무기 | 水 + 木 | 4 | 金 보너스 4 | 용이 되지 못한 큰 뱀 |
| 3 | 용(龍) | 水 + 水 | 8 | - | 승천 완성 |
- 시장 구매 비용(1단계): 水2 金1 (가안).
- 주의: 용 디자인은 고분벽화·민화의 사신도 계통 참조, 드래곤볼·하쿠 디자인 회피.

#### 라인 3. 새끼 호랑이 -> 산군 -> 백호 (金, T2 라인)
| 단계 | 이름 | 보너스 | 총점 | 변화 조건 | 서사 |
|---|---|---|---|---|---|
| 1 | 아기 범 | 金 | 1 | 土 보너스 2 | 민화 속 까치호랑이의 새끼 |
| 2 | 산군(山君) | 金 + 土 | 3 | 土 보너스 4 | 산을 다스리는 호랑이 |
| 3 | 백호(白虎) | 金 + 金 | 6 | - | 서방의 사신(四神) |
- 시장 구매 비용(1단계): 金1 土2 水1 (가안).
- 주의: 호돌이·수호랑 등 마스코트 회피.

보너스 +1이 큰 폭이므로 변화는 강력한 보상. 변화 조건 N(2, 4)은 후반 보너스 총량(대략 15~18)과 비교해 시뮬로 조정한다.

### 2.4 멀티 전용 상호작용 (캐주얼 유지 원칙: 직접 공격·탈취 없음, 양의 합)
1. **공명(共鳴)**: 내가 변화하면, 변화한 크리처와 같은 오행 색 크리처를 1개 이상 보유한 상대는 해당 색 기운 1개를 즉시 받는다(상대당 1개, 공급 부족 시 못 받음).
   - 효과: 남의 턴에도 이득이 생겨 대기 지루함 감소(비동기에 특히 중요), 변화가 "축제" 느낌, 견제 없이 색 겹침이 약한 상호작용으로 작동.
   - 균형 장치: 변화한 플레이어에게 불이익 없음. 공명 이득은 소액.
2. **하늘의 징조(天兆)**: 라운드마다 공개 카드 1장(다음 라운드 징조도 예고). 전 플레이어에게 동일 적용되는 대칭 효과.
   - 예) 보름달: 이번 라운드 木 기운 획득 시 +1 / 폭우: 水 크리처 구매 비용 -1 / 일식: 여의주 획득 시 +1.
   - 효과: 매판 변주 + 예고로 계획 수립, 직접 견제 없음.
- 의도적 배제: 구슬 훔치기, 카드 파괴, 강제 교환(캐주얼 훼손). 이모트/응원 같은 소셜 기능은 별도 사회 기능 항목으로 열린 질문.

## 3. 1판 목표

| 항목 | 값 (가안) |
|---|---|
| 인원 | 2~4인 |
| 목표 플레이타임 | 실시간 12~18분 (3인 기준 중앙값 15분), 2인 10~14분 |
| 승리 점수 | 15점 (스플렌더 동일). 변화로 점수 가속이 있어 시뮬 후 14~16 조정 |
| 평균 턴 수 | 인당 약 9~12턴 (시뮬 목표) |
| 하드캡 | 인당 25턴 도달 시 강제 종료, 점수 최고 승리 (교착 방지) |
| 종료 | 15점 도달 시 해당 라운드를 끝까지 진행(동일 턴 수 보장) |
| 귀족 점수 | 3점 |
| 튜토리얼 | 첫 판은 가이드 1판(5분 내): 구매 -> 보너스 -> 변화 1회 체험 |

수용 기준(밸런스):
- AI 시뮬 1,000판에서 평균 길이가 위 범위 안, 선후공 승률 편차 +-5%p 이내, 변화를 한 번도 못 하고 이기는 비율 20% 이하.

## 4. 멀티 모드 구조

두 모드가 **같은 서버 권위 턴제 엔진**을 공유하고 타이머/알림만 다르게 한다. MVP는 둘 다 같은 구조로 개발 가능.

| 구분 | 퀵매치 (실시간 턴제) | 퇴근길 매치 (비동기 턴제) |
|---|---|---|
| 상황 | 점심/쉬는 시간, 한 번에 15분 | 출퇴근, 회의 사이 틈틈이 |
| 매칭 | 랜덤 매칭 + 친구방 | 친구방 + 랜덤 매칭(대기 허용) |
| 턴 타이머 | 45초 (복귀 지연 보호용 첫 3턴 +15초) | 12시간 (프리셋 4h / 12h / 24h) |
| 제한 시간 총합 | 약 15~20분 | 약 2~4일 (4인 24h 프리셋은 최대 길어짐 -> 경고 표시) |
| 타임아웃 처리 | 자동 행동: 기운 상한 내 가능한 3색 획득이 없으면 패스. 변화는 "자동" 설정 시만 | 동일. 알림 후 80%, 100% 시점 푸시 |
| 이탈 처리 | 연속 2회 타임아웃 시 봇 대행(복귀 가능), 3회 시 이탈 판정 | 연속 2회 -> 봇 대행, 3회 -> 이탈 판정 |
| 이탈 시 | 남은 인원 계속, 이탈자 점수 상태 유지하여 순위 하위 | 동일. 2인 판이 이탈되면 잔류자 승리(보상 감소) |
| 푸시 | 불필요 | 내 턴, 변화 가능, 종료 알림 |

권장:
- 출시는 "서버 권위 턴제 엔진 + 2개 프리셋"으로 시작. 실시간 웹소켓과 비동기 푸시는 같은 이벤트 로그로 구현 가능.
- 비동기 모드의 대기 지루함은 **공명** 이득과 "상대 턴 리플레이 요약"으로 완화.
- 여러 판 동시 진행(최대 5판)을 비동기에서 허용하는 것이 직장인 습관에 맞음. 동시 진행 수는 열린 질문.

## 5. 열린 질문
1. **오행 + 신화 결합 확정 여부.** 해외 출시 비중이 높다면 서양 신화 비율을 몇 %로 둘 것인가. (기획 제안: 동양 70 / 서양 30)
2. **법무 검토:** "스플렌더" 룰 차용의 허용 범위와 명칭 사용 금지 여부. 게임명 상표 검색 시점.
3. **아트 제작 방식:** 생성형 AI 사용 허용 여부와 허용 시 최종 수작업 보정 의무. 아트팀 IP 체크리스트 필요.
4. **조커 대체 규칙(변화 조건 1칸 대체)** 이 조커 가치를 과도하게 올리는지 시뮬로 확인 필요. 대안: 대체 시 점수 -1 등.
5. **변화가 턴 종료가 아닌 무료 행동**이어서 강력해질 수 있음. 대안: 턴당 1회 + 기운 1개 소모.
6. **단독 전설 카드**(변화 없음)를 허용할지. 허용 시 몇 장?
7. **승리 점수 15** 가 변화 가속 하에서 적정한지(시뮬 필요).
8. 비동기 모드의 최대 동시 진행 판 수, 랜덤 매칭 대기 정책.
9. 친구 초대, 이모트, 랭킹 등 소셜 요소의 MVP 범위.
10. 4인 시 귀족 수(5)와 시장 카드 수 조정 필요 여부.
11. 수익화 모델(광고/스킨/패스) 방향: 카드 일러스트 스킨과 IP 리스크 상호 영향.
12. 색각 이상/접근성 요구 수준(한자·문양 병기 외 추가 조치).

## 6. 타팀 요청사항
- **프로그래밍:** 도감 슬롯 모델(라인 세트가 구매자에게 귀속), 변화 = 자유 행동 규칙, 서버 권위 이벤트 로그 구조 검토 의견 요청. (구현은 명세 확정 후)
- **아트:** 오행 5색 팔레트 + 색각 대응 아이콘 규칙, IP 회피 체크리스트 반영한 레퍼런스 정책(2절 IP 목록).
- **사운드:** 변화 연출/공명 SFX 이벤트 후보 (변화, 공명, 징조 공개).
- **QA:** 엣지 케이스(2.2절) 및 수용 기준(3절)을 테스트 케이스로 변환 준비.
