# 한국 설화·역사 로스터 (roster-korea)

결정 D11. 오행 신수 로스터 대체. 데이터 원본: `roster-korea.json`. 수치(cost/points/evolveReq)는 `src/data/cards.js` 그대로. id 슬롯에 캐릭터만 배정.

## 1. 구조 (cards.js 분석)
- 3단 라인 12개 (36장): t1-001~012 -> t2-001~012 -> t3-001~012. 라인 내 색 동일.
- 2단 라인 18개 (36장): t1-013, 016~031, 033 -> t2-013~030. 색은 단계마다 다를 수 있음.
- 단일 8장: T1 5 (t1-014, 015, 032, 034, 035) + T3 3 (t3-013, 014, 015).
- 희귀 5 + 전설 10 중 5 = R/L 10장.

## 2. 색 체계: 오방색 구슬 (코드 키 유지)
| 코드 키 | 표시 | 한자 | 방위 | 구슬 | hex | edge |
|---|---|---|---|---|---|---|
| monster | 적 | 赤 | 남 | 적주 | #D63B35 | #7A1F1A |
| super | 흑 | 黑 | 북 | 흑주 | #343B4D | #12151F |

- 백주는 밝은 배경에서 edge 외곽선 필수. 구슬 중앙에 한자 표기로 색각 이상 대응.
- 카드 color = cards.js bonus 키. R/L 은 color + color2.
- 일반 카드 팔레트는 color 계열 3종 중 선택(JSON `colors.palettes`). R/L 은 두 색 혼합 전용 팔레트.

## 3. 용어 추천
- 진화 버튼: **성장** (대안: 이어가기, 인연). 소년->왕, 알->인물, 이무기->용, 사물->인물 변신까지 포괄.
- evolveReq 표기: 성장 조건. 마스터볼: 여의주.
- 라인 연결 종류(JSON `lines[].link`): 성장 / 변신 / 인연 / 보은 / 계승 / 탄생.

## 8. 가정 및 방침
- 실존 인물은 존중 묘사. 별명성 호칭(바보 온달, 관노 장영실)은 이름에서 제외(산골 온달, 동래 소년).
- 현대 드라마·영화·웹툰 고유 설정 미사용(예: 허준의 가상 스승 인물, 저승사자 현대 복장 등).
- 오누이, 견우직녀, 해와 달 등 둘이 한 쌍인 카드는 스프라이트 1인 대표 + 소품으로 표현(아트팀 판단).
- 홍길동은 허균의 소설 속 인물(허구)이나 인지도 기준으로 포함.
- 신규 archetype `object`(shape 11종) 필요 -> 아트팀 요청.
- JSON `colors.a11y_note` 는 문자열 키이므로 colors 순회 시 건너뛸 것(프로그래밍팀).
