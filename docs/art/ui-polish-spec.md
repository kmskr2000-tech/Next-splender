# UI 폴리시 명세 v1 (기본 도트 버전)

목표: "습작" 인상 제거. 도트 캐릭터는 유지하되, 그 주변 UI는 절제된 상용 게임 수준으로.
원칙: **도트는 캐릭터와 숫자에만, 나머지는 깔끔하게.** 장식은 한 곳(카드)에 집중하고 나머지는 조용히.

## 1. 진단 (현재 문제)
- 모든 요소에 동일한 두꺼운 검정 테두리 + 오프셋 그림자 → 위계 없음, 아마추어 인상
- 색 체계 부재: 파랑 헤더, 겨자 버튼, 청록 타이머, 보라 전설, 연두 TIP이 뒤섞임
- 카드 정보 과밀: "→ 동명성왕 (청자 보너스 4)", 점선, "최종 성장", 박스형 비용 칩
- 티어 행 라벨(큰 빨간 숫자 + "3단계") 어색
- 상대 레일 카드 과대, 하단 도크에서 자원 중복 표기, TIP 배너 상시 노출
- 본문까지 픽셀 폰트 → 가독성·고급감 저하

## 2. 디자인 토큰
### 색 (한지·먹·주칠·금)
| 토큰 | 값 | 용도 |
|---|---|---|
| --paper | #F7F1E6 | 앱 배경 (한지, 아주 옅은 섬유 노이즈 텍스처 2% 허용) |
| --paper-2 | #EFE6D6 | 섹션 배경, 마켓 판 |
| --card | #FFFDF8 | 카드 면 |
| --ink | #23201C | 본문 |
| --ink-2 | #6E6558 | 보조 텍스트 |
| --line | #E2D7C5 | 1px 구분선 |
| --lacquer | #1F2A3A | 헤더·도크 (먹·흑칠 남색) |
| --on-lacquer | #F3ECE0 | 헤더 위 텍스트 |
| --vermilion | #C8402F | 주 강조(주칠): 내 차례, 주요 버튼 |
| --gold | #C9A24A | 점수, 전설, 진행 링 |
| --jade | #4E8F7E | 성공·성장 가능 |
| 티어 띠 | T1 #B88A5A(동) · T2 #9AA3AD(은) · T3 #C9A24A(금) · 희귀 #4E8F7E(옥) · 전설 그라데이션 #C9A24A→#C8402F |
보물 자원색(--monster 등)은 현행 유지. 아이콘이 색을 담당하므로 칩 배경에 자원색을 깔지 않는다.

### 타이포
- 숫자·점수·카드 이름·화면 제목: Galmuri11 (도트 정체성)
- 본문·버튼·설명: 시스템 산세리프 `"Pretendard","Apple SD Gothic Neo","Noto Sans KR","Malgun Gothic",sans-serif`
- 스케일: 11 / 12 / 14 / 16 / 20 / 28 px. 한 화면에 4단계 이하.
- 숫자는 `font-variant-numeric: tabular-nums`

### 모양·깊이
- 반경: 카드 10px, 칩 999px, 패널 14px, 버튼 12px
- 테두리: 기본 1px var(--line). 두꺼운 검정 테두리 전면 폐지.
- 그림자 2단계만: `--sh-1: 0 1px 2px rgba(35,32,28,.08), 0 2px 6px rgba(35,32,28,.06)`, `--sh-2: 0 6px 20px rgba(35,32,28,.14)` (선택·드래그·모달)
- 간격: 4px 그리드 (4/8/12/16/24)

## 3. 컴포넌트
### 카드 (마켓, 72~84px 폭 기준)
```
┌──────────────┐  ← 상단 3px 티어 띠(동/은/금/옥/전설)
│ 3        (◎) │  점수: 좌상단 Galmuri 18px 금색(0점이면 숨김) / 보너스: 우상단 22px 원(흰 바탕+아이콘)
│   [ 도트 ]   │  아트 영역: 보너스 자원색 8% 틴트 원형 그라데이션 배경, 스프라이트 pixelated
│  이순신       │  이름: Galmuri 12px 가운데
│ ◉4 ◉3 ◉2  ↗ │  비용: 아이콘16+숫자 pill 가로 배열(줄바꿈 허용) / 성장 가능: 우하단 작은 ↗ 배지(jade)
└──────────────┘
```
- 성장 경로 문구·"최종 성장"·"성장 없음"·점선 제거 → 상세 시트에서만 표시
- 살 수 있음: 테두리 2px var(--jade) + 미세 글로우. 선택: --sh-2 + 2px var(--vermilion)
- 희귀/전설: 띠 + 아트 배경에 은은한 광채, 라벨 pill("희귀"/"전설") 이름 위 9px

### 마켓 판
- 판 배경 var(--paper-2), 패널 반경 14px, 내부 여백 8px
- 티어 라벨: 행 왼쪽 18px 폭 세로 탭(티어 띠 색) + 남은 덱 수 작은 숫자. 큰 빨간 숫자 폐지

### 헤더 (상단)
- 높이 48px, 배경 var(--lacquer). 좌: 라운드 "R9", 중: 현재 차례 플레이어 아바타+이름(내 차례면 주칠 pill "내 차례"), 우: 원형 타이머 링(남은 시간 비율, 10초 이하 주칠) + 메뉴 아이콘
- 별도 타이머 바·TIP 배너 제거. TIP은 하단 도크 위 1줄 토스트(3초 후 사라짐, 탭으로 닫기)

### 플레이어 레일 (우측, TFT 참고)
- 항목 56px 정사각: 아바타 원 44px + 바깥 **진행 링**(점수/21, 금색) + 우하단 점수 숫자 배지
- 현재 차례: 링 주칠 + 좌측 3px 주칠 바. 봇: 회색 작은 "BOT" 꼬리표
- 이름은 탭/롱프레스 시 툴팁. 레일 폭 64px로 축소 → 마켓 확장

### 하단 도크
- 배경 var(--lacquer), 상단 반경 16px
- 1행: 내 아바타+점수(Galmuri 20 금) · 보물 6종을 **한 줄**로: 아이콘 28px + 보유수(큰 숫자) + 보너스(+n, 작은 jade 숫자) 통합 표기. 중복 행 제거. 우측 "10개 중 n" 작은 텍스트
- 2행: 주 행동 버튼 1개 전폭(주칠, 높이 48px, 상황별 문구) + 보조 "취소" 텍스트 버튼
- 안내 문구는 토스트로

### 버튼
- 주: 배경 --vermilion, 글자 #fff, 반경 12, --sh-1. 눌림 시 translateY(1px)
- 보조: 투명 + 1px 테두리 --line
- 비활성: 불투명도 .45, 그림자 없음

### 홈·결과·상점
- 같은 토큰 적용. 홈 상단 히어로는 대표 인물 도트 3명 일렬(크게, 바닥 그림자) + 타이틀
- 매칭 버튼 = 주 버튼, 모드 탭 = 세그먼트 컨트롤(배경 --paper-2, 선택 칸 흰색 + --sh-1)

## 4. 모션 (절제)
- 카드 획득: 카드가 도크로 날아가며 축소(250ms ease-out)
- 성장: 카드 위 금빛 원형 확산 1회(400ms) + 아트 교체
- 내 차례 시작: 헤더 pill 살짝 튐(scale 1.06, 200ms)
- prefers-reduced-motion 존중

## 5. 수용 기준
- 두꺼운 검정 테두리·오프셋 그림자 0개
- 화면당 강조색은 주칠·금 2개만 (자원 아이콘·티어 띠 제외)
- 마켓 카드 72px 폭에서 이름·점수·비용 판독 가능
- 390×844에서 스크롤 없이 마켓 3행 + 희귀/전설 + 도크 모두 보임
- 대비 4.5:1 이상
