# GPT 이미지 생성 프롬프트: 카드 화풍 3종

사용법
1. 새 대화에서 **공통 지시**를 먼저 보낸다. 이때 참고 이미지 3장(풀아트 카드 / 파스텔 카드 스킨 / 클래시풍 덱)을 함께 첨부한다.
2. 화풍 프롬프트를 하나씩 보낸다. `{인물}` 자리에 아래 **인물 설명** 블록을 붙여 넣는다.
3. 같은 인물을 세 화풍으로 만들어야 비교가 된다. 이순신 → 세종대왕 → 해태 순서를 권장한다.

---

## 공통 지시 (첫 메시지)

```
한국 문화(전래동화·설화·고대~조선 역사 인물)를 소재로 한 모바일 카드 게임의 캐릭터 카드 일러스트를 만들려고 해. 같은 인물을 3가지 화풍으로 그려서 비교할 거야.

첨부한 참고 이미지 3장은 분위기와 완성도 기준으로만 참고하고, 캐릭터·구도·로고·글자는 절대 따라 하지 마. 모든 캐릭터는 오리지널 디자인이어야 해.

공통 규칙:
- 세로 3:4 비율, 카드 일러스트 한 장에 인물 1명(또는 1마리)
- 이미지 안에 글자, 숫자, 로고, 워터마크, 카드 테두리 넣지 않기 (테두리와 글자는 게임 UI에서 따로 얹음)
- 실존 역사 인물은 존중하는 묘사. 희화화 금지. 조선시대 복식 고증을 최대한 반영
- 드라마·영화·웹툰·기존 게임 캐릭터의 얼굴이나 디자인을 닮지 않게
- 카드가 휴대폰에서 작게(폭 약 80px) 보여도 실루엣과 얼굴이 알아볼 수 있게 인물을 크게, 배경은 인물보다 덜 복잡하게

준비되면 "준비 완료"라고만 답해줘. 이어서 화풍별로 요청할게.
```

## 인물 설명 블록

**이순신**
```
조선 수군 장수 이순신. 40대 남성, 단정한 콧수염과 턱수염, 결연하고 침착한 눈빛. 붉은 상모가 달린 철제 투구, 놋쇠 징이 촘촘히 박힌 남색 두정갑, 허리에 환도. 배경 소품: 용머리가 달린 거북선, 남해 바다의 파도.
```

**세종대왕**
```
조선 4대 임금 세종대왕. 40대 남성, 온화하고 지혜로운 표정, 단정한 수염. 검은 익선관, 가슴에 금색 용 보(원형 무늬)가 있는 붉은 곤룡포, 옥대. 손에 책이나 두루마리. 배경 소품: 해시계(앙부일구), 측우기, 은은한 궁궐 처마.
```

**해태**
```
조선의 상상 속 수호 신수 해태. 사자와 비슷하지만 머리 가운데에 뿔이 하나 있고, 곱슬곱슬한 갈기와 비늘 무늬 몸, 정의를 지키는 늠름한 표정. 색은 돌빛 회청색에 금빛 장식. 배경 소품: 궁궐 앞 돌계단, 구름.
```

## 화풍 ① 생동감 있는 풀아트 카드

```
화풍 ① — 프리미엄 수집형 카드의 "풀아트" 일러스트로 그려줘.

인물: {인물}

화풍 지시:
- 카드 전체를 채우는 풍경 속 인물. 인물이 화면의 60% 이상을 차지
- 애니메이션풍 반실사 페인팅, 부드러운 셀 셰이딩과 풍부한 배경 디테일
- 아침 햇살이나 역광 같은 극적인 빛, 반짝이는 공기감, 생동감 있는 포즈(정지 증명사진 금지)
- 색은 선명하지만 자연스럽게, 배경은 살짝 흐려서 인물이 돋보이게
- 나중에 홀로그램 효과를 얹을 것이므로 하늘·물·빛 영역을 넉넉히

출력: 3:4 세로 1장, 글자·테두리 없음.
```

## 화풍 ② 파스텔 플랫 일러스트 (카드 스킨풍)

```
화풍 ② — 아기자기한 파스텔 플랫 벡터 일러스트로 그려줘. 캐주얼 카드 게임의 "카드 스킨 세트" 앞면 그림 느낌.

인물: {인물}

화풍 지시:
- 단순한 도형 위주의 플랫 벡터, 얇은 선이나 선 없음, 은은한 종이 질감
- 귀엽지만 품위 있는 비율(머리 약간 크게, 2.5~3등신은 아님 — 4등신 정도)
- 파스텔 톤: 크림 바탕, 민트·코랄·연남색·연한 금색 위주. 채도 낮게
- 한국 전통 문양(청해파 물결, 구름, 매화, 단청 패턴 중 인물에 어울리는 것)을 배경이나 가장자리 장식으로
- 그림 안에 장식 테두리 패턴은 넣어도 되지만 글자는 금지

추가 요청: 같은 세트의 "카드 뒷면" 무늬 1장도 따로 만들어줘. 인물 없이 전통 문양만, 같은 색감, 3:4 세로.
```

## 화풍 ③ 클래시풍 3D 카툰

```
화풍 ③ — 모바일 전략 게임 카드에 쓰이는 굵직한 3D 카툰 렌더 스타일로 그려줘.

인물: {인물}

화풍 지시:
- 큰 머리와 과장된 비율, 두툼하고 둥근 형태, 매끈한 3D 렌더 질감(점토·장난감 같은 광택)
- 과장된 표정: 자신감 있는 미소나 결연한 표정, 눈썹 굵게
- 상반신~허리 위 클로즈업, 정면 또는 살짝 3/4, 카드 칸 안에 꽉 차게
- 배경은 단순한 파란색 계열 그라데이션(인물이 튀도록)
- 밝은 림 라이트, 선명한 원색 포인트

출력: 3:4 세로 1장, 글자·테두리·레벨 표시 없음.
```

## 결과 받은 후

- 세 화풍 × 세 인물 = 9장을 받으면 한 번에 올려줘. 인게임 카드 크기(폭 약 80px)로 줄여서 가독성까지 비교한다.
- 마음에 드는 화풍이 정해지면, 그 화풍으로 같은 인물의 **성장 3단계**(예: 무과급제생 → 이순신 → 삼도통제사)를 일관성 있게 만드는 후속 프롬프트를 따로 작성한다.
